# Cockpit de pilotage — atelier 10 minutes

Tableau de bord de pilotage pour dirigeant de TPE/PME, à remplir en direct.
Le dirigeant choisit son secteur, répond à 8 questions, et son cockpit se construit
en temps réel — avec un diagnostic automatique du point d'attention n°1.

- **Page** : `index.html` (fichier unique, aucune dépendance, rien n'est envoyé sur internet)
- **Secteurs couverts** : générique, BTP/artisanat, services & conseil, commerce, restauration/CHR, e-commerce, santé, industrie
- **Usage** : partager le lien pendant une vidéo, le dirigeant remplit en parallèle

## Mise en ligne (GitHub Pages)

1. Pousser ce dossier sur un dépôt GitHub.
2. Settings → Pages → Source : `Deploy from a branch` → branche `main`, dossier `/ (root)`.
3. L'URL publique apparaît après ~1 min : `https://<compte>.github.io/<repo>/`.
